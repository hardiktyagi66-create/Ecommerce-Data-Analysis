E-Commerce Sales & Customer Analytics Dashboard
Project Overview

This project analyzes customer behavior, product performance, sales trends, and customer satisfaction for a global e-commerce business using Power BI and DAX.

The dashboard helps stakeholders monitor key business metrics, identify growth opportunities, improve customer retention, and make data-driven decisions.

Business Problem

E-commerce companies generate large volumes of data from customers, orders, products, and reviews. The objective of this project is to transform raw data into actionable insights that support business growth and operational efficiency.
